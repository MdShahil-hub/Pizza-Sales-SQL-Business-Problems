# 🍕 Pizza Sales Analysis using MySQL

## 📌 Project Overview
This project analyzes pizza sales data using MySQL to identify sales trends, customer preferences, and revenue insights. SQL queries are used to answer business-related questions and support data-driven decision-making.

## 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## 📂 Dataset
The dataset contains information about:
- Orders
- Order Details
- Pizzas
- Pizza Types

Since the dataset was large, I created the database tables manually with appropriate columns and data types, then imported the original data from source files.

## 🔍 Key Analysis
- Total revenue generated
- Total orders and pizzas sold
- Most popular pizza sizes
- Best-selling pizza types
- Revenue contribution by pizza category
- Sales trends by hour and day
- Top 3 pizza types by revenue in each category
- Cumulative revenue over time

## 💡 Key Skills Demonstrated
- Data importing and database management
- SQL JOINs and aggregate functions
- GROUP BY and ORDER BY
- Subqueries and Common Table Expressions (CTEs)
- Window functions
- Date and time analysis
- Business problem-solving using SQL

## 🎯 Project Objective
To transform raw pizza sales data into meaningful business insights using SQL and demonstrate practical data analysis skills.
